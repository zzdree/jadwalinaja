# JadwalinAja

Proyek pengatur jadwal perkuliahan mingguan untuk mahasiswa, dibangun di atas stack React, Vite, TypeScript, Tailwind CSS, dan Cloudflare Pages + D1 Database.

<!-- antislop:start -->
## antislop
Untuk pengerjaan UI, teks/copywriting, aksesibilitas, layout mobile, atau komentar kode, baca `.claude/skills/antislop/SKILL.md` (core) dan skill terkait berikut:
- UI / visual: `.claude/skills/antislop-ui/SKILL.md`
- Copy & text: `.claude/skills/antislop-copywriting/SKILL.md`
- People / Accessibility: `.claude/skills/antislop-human/SKILL.md`
- Mobile / responsive: `.claude/skills/antislop-layoutmobile/SKILL.md`
- Code comments: `.claude/skills/antislop-code/SKILL.md`

Sebelum memulai pekerjaan UI, terapkan aturan antislop secara langsung (Mode 1: During) dan jalankan Delivery Gate sebelum selesai.
